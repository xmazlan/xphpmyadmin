# Penerimaan SSH dan diagnostik v2 — 23 Oktober 2026

Implementasi tersedia untuk cakupan teruji di bawah. Hasil aktual otomatis:
[laporan JSON](2026-10-23-v2-regression.json). Regresi dan suite SSH lulus.
Seluruh database pengujian disposable; SQL tulis hanya pada tabel `import_probe`
fixture. Tidak ada query ke database remote pengguna untuk migrasi/validasi.

## Runtime dan keputusan dukungan

Mac, PHP CLI 8.5.12, Herd PHP 8.4.27 FPM (`fpm-fcgi` pool disposable), OpenSSH 10.2p1 / LibreSSL 3.3.6,
MySQL 9.4.0, MariaDB 11.4.13. Chrome pada Mac dipakai untuk QA drawer SSH,
fingerprint, penonaktifan aksi saat Test, diagnostik actual dan retensi input.
Fixture sshd menonaktifkan PerSourcePenalties agar rangkaian auth/key negatif
tidak membatasi tes berikutnya dari loopback; konfigurasi sshd pengguna tidak diubah.
Pool FPM uji dibuat terpisah; konfigurasi pool Herd pengguna tidak diganti.

SSH non-TLS eksplisit dan direct/TLS tersedia. **SSH + TLS ditolak `tls_tunnel`**:
mysqli belum mempunyai peer hostname terpisah yang dibuktikan pada implementasi
ini. Tidak ada klaim sertifikat SAN logis berhasil lewat tunnel dan tidak ada
downgrade. Batas ini sesuai jalur penolakan kombinasi tidak didukung dalam brief.

Scheduler lokal sudah diaktifkan melalui LaunchAgent
`id.xmazlan.xphpmyadmin.local-ssh-sweep`, interval 60 detik, akun pemilik PHP,
PHP/config absolut dan log privat. `launchctl` mengonfirmasi initial exit 0.
On-request sweep tetap aktif. Aplikasi web tidak memasang scheduler sendiri;
pada instalasi lain operator mengikuti panduan. LaunchAgent ini berlaku saat
akun login dan tidak menjalankan koneksi database remote.

## Aktivasi metadata lokal

Store aktif dimigrasikan setelah backup penuh metadata/master key dan verifikasi
restore disabled ke lokasi baru. Dua profil lama dipertahankan; seluruh baris
profil/import/ciphertext/registry identik, konfigurasi dan key tidak diganti,
inode/identitas store sama. Hanya kolom/tabel schema 3 ditambahkan. Halaman Herd
`local-connections.php` HTTP 200; CLI sweep berhasil. Bukti dan backup lengkap
tersimpan privat di direktori `v2-backups-*` instalasi; tidak dimasukkan repo.

## Batas pemulihan dan tindakan operator

Registry lease rusak/hilang dipulihkan memakai ownership receipt. Bila receipt
dan lease sama-sama hilang/rusak, aplikasi menolak menebak kepemilikan/kill proses;
operator harus memeriksa kontrol lokal. Kehilangan seluruh storage proses secara
bersamaan tidak dicakup oleh janji pemulihan otomatis.

Request/query yang terputus tidak direplay. Hasil query tulis dapat tidak pasti
sesudah putus jaringan. Verifikasi data sebelum mengulangi query. Tes tidak
membuktikan semantik exactly-once pada jaringan terputus.

Untuk mengulang pengujian dibutuhkan tools fixture MySQL/MariaDB yang dijelaskan
pada [panduan koneksi](../tes-koneksi-dan-tls.md), executable system sshd/ssh-agent,
dan binary Herd PHP 8.4 FPM. Suite tidak mengunduh tools atau memakai DB existing.
